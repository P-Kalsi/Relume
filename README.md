# Relume

Real-time, on-device AI relighting for video calls.

Relume uses monocular depth estimation and GPU shaders to apply adjustable virtual lighting to a webcam feed.

## Technology

- C++20
- Dawn / WebGPU
- WGSL
- ONNX Runtime
- CoreML on macOS
- CMake
